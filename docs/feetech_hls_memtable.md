# 1 舵机通信协议
舵机使用FT-SCS自定义协议，出厂时的串口默认配置，波特率默认为1Mbps，数据位 8，无校验，停止位 1；波特率可配置范围38400~1Mbps，默认通信地址（站号）为1。
[FT-SCS 自定义协议](http://doc.feetech.cn/#/tiaozhunlujingft?srcType=FT-SCS-Protocol-41ad23fe8a244712ba160b93)

# 3 特殊字节解释
## 3.1 舵机相位
- **位数/位权重：说明**
- BIT0（1）：伺服相位(固件版本<=3.41)，磁编码支持(0:AS5600，1:MT6701，固件版本>=3.44)
- BIT1（2）：电流反馈方向相位；(0)正向，(1)反向
- BIT2（4）：驱动桥方向相位；(0)正向，(1)反向
- BIT3（8）：速度方向相位(固件版本<=3.41)
- BIT4（16）：角度反馈模式；(0)反馈单圈角度，(1)反馈全角度
- BIT5（32）：驱动桥配置，(0)独立H桥，(1)集成H桥
- BIT6（64）：PWM频率，(0)24kHz，(1)16kHz
- BIT7（128）：位置反馈方向相位，(0)正向，(1)反向
- <div style="padding: 8px 16px;background-color: #fff9e9;border-radius: 4px;border-left: 5px solid #fbc302;margin: 20px 0;">如果同时设置多个位，舵机的相位值为各个位值之和。例如：原相位值为0，舵机运行反向，则相位值为128+4+2=134；
</div> 

## 3.2 舵机状态
**舵机状态：0表示正常，1表示异常**
- **位数/位权重：说明**
- BIT0（1）：电压状态
- BIT1（2）：磁编码状态
- BIT2（4）：温度状态
- BIT3（8）：电流状态
- BIT4（16）：----
- BIT5（32）：负载状态
- BIT6（64）：----
- BIT7（128）：----
- <div style="padding: 8px 16px;background-color: #fff9e9;border-radius: 4px;border-left: 5px solid #fbc302;margin: 20px 0;">如果同时有多种状态，舵机的状态值为各个位值之和。例如：电压过压/欠压与舵机过热，则舵机状态值为4+1=5；
</div>

- BIT3（8）：过流保护
