## 4.5 `kt` 实测（空载恒速法，2026-09-10 追加，不需要电流表）

**动机**：`kt`/`R` 此前是**说明书值**（0.7358 / 3.75）被钉死在拟合里，而电气模型里所有项只依赖比值
`kt/R`（`I = duty·vin/R − (kt/R)·ω`，且 mode 4 电流钳位永不触发）⇒ `kt/R` 错多少，摩擦就会被带偏多少。

**方法**（`microduck_rl/scripts/measure_kt_free_run.py`）：拆掉摆杆让舵机**空载**，命令 6 档恒定角速度
线性斜坡（双向、来回共 24 腿），稳态时 `duty·vin = ke·ω + (I₀+τ_C/kt)·R` ⇒ 对 `|duty|·vin` 与实测 `|ω|`
回归，**斜率就是 `ke ≡ kt`**（SI 恒等式）。全程只用编码器 + 占空比 `reg60` + 电压 `reg62`，**不含任何电流量**，
因此与 `reg69` 那 6.6 倍的刻度误差无关。

**结果**：

| 项 | 值 |
|---|---|
| 回归 | `\|duty\|·vin = **0.6921**·\|ω\| + 0.0542`，**R²=0.9983**（24 腿，ω 覆盖 0.64–4.1 rad/s） |
| 正/反向 | 0.6886 / 0.6956（差 1.0%）→ 无方向性偏差 |
| **`kt` 实测** | **0.692 N·m/A = 说明书的 94%** |
| 粘性修正后 | `ke ≈ 0.646`（斜率含 `friction_viscous·R/kt ≈ 0.046`）⇒ 说明书偏高 **6–12%** |
| 截距 | 0.0542 V ⇒ **裸舵盘库仑摩擦 ≈ 0.0100 N·m** |

**交叉验证**：裸舵盘摩擦 0.0100 N·m **小于**带载拟合的 `friction_base` 0.0149 N·m，差值 0.005 正对应
**负载相关摩擦** ⇒ 与"`duty/B` 随负载单调上升"这条独立证据一致。

**结论**：说明书的 `kt` 偏高 6–12%；按"实测为准"原则改用实测值重跑拟合（`--set "{'kt': 0.692, ...}"`），
比对摩擦参数位移。⚠️ 脚本注意：`ω` 设定值曾因循环开销而偏低（设定 5.0 实测 4.0 rad/s），
已改为**按真实时间插值目标**；回归始终用实测 ω，故本次结果有效。

## 6. 本次踩到并已修的问题（脚本/文档均已同步）

1. **电流中止误报**：HD mode 4 的 `reg69` 不可信（起步瞬态恒 ≈2.1 A、出现 −3.0 A、峰值 4.06 A > 物理堵转 1.39 A）→ 脚本按型号自动选阈值，**HD 默认关闭电流中止**，改用**位置误差卡死检测**（0.8 rad × 1.0 s）。HLS 保持 1.0 A。
2. **`read_frame` 短帧崩溃**：`LEN=0` 噪声帧放行后 `body[0]` 抛 `IndexError`，一条坏帧杀掉整档采集 → 现 `LEN<2` 按超时丢弃。
3. **起跑状态**：记录间隙改为**逐拍重写目标**的主动稳位（单发目标不生效），连续 `|q|<0.02 rad`、`|dq|<0.25 rad/s` 保持 0.25 s 才起跑 → `pos@t0` 从 −0.635 rad 降到 ≤0.44°。
4. **台架障碍与限幅**：实测摆动平面两侧硬障碍 **正 +96.7° / 负 −88.4°**（负侧顶住时占空比 100%）→ 默认 `--amp-max-deg 80`（超限轨迹整体缩放保波形）+ `--hard-limit-deg 86`（运行时断扭）。
5. **`reg31` 结论更正**：判别实验证明 mode 4 **控制环确实使用 reg31**（`0x0080`→−128 LSB；命令未偏置目标时舵机按偏置值移动），推翻 2026-09-09 "只偏置读数"的结论；但**仍不可用它居中**——它只改报数，原始读数与目标钳位 [0,4095] 不变，会骗过零位守卫（详见 `hd1910_servo_notes.md` §6.3）。
6. **USB 链路**：转接板当日多次掉线重枚举（`/dev/ttyACM0` 节点 12:53、15:15 重建，设备号 002→009），导致采集瞬时中断；与供电电压无关（全程 5.1 V）。处置：短线直插、接头检查、舵机电源与 USB 共地良好。
